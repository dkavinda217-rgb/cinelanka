# CineLanka

Dark movie library with search, a video player and a browser-local catalog editor.

## Edit movies
Click Manage movies. Add the title, year, rating, genre, image URL and direct MP4/WebM URL. You can edit/remove entries and import/export JSON backups. Changes stay in your current browser. Download movies.js and replace the repository's movies.js to publish your catalog for everyone. No GitHub tokens belong in this website.

## Hosting
GitHub Settings > Pages > Deploy from a branch > main > /(root) > Save. All files are static; no build is required.

## Playback
Use a direct HTTPS video file URL that permits playback from this site. YouTube and Google Drive sharing pages are not video files. Native playback depends on browser codec support and source server restrictions. The demo links require an internet connection. Movies themselves are hosted by their source servers, not GitHub Pages.

## Local preview
Open index.html, or serve the folder with any static HTTP server.
